### ABOUT THE DATA
This dataset covers match-by-match performance for 229 footballers across 47 clubs during the 2025/26 season, including league, cup, Champions League, qualifiers, and the FIFA World Cup 2026. You'll find stats like goals, assists, minutes played, pass accuracy, distance covered, cards, and a performance rating for each match. This cleaned version fixes a bunch of data quality issues from the original — unrealistic match counts, red cards that didn't make sense with minutes played, inconsistent injury flags, duplicate match IDs, and ratings that didn't actually reflect performance — so it's much more reliable to work with now. Just a heads up: the match data itself is simulated, not pulled from real games, so treat it as a solid practice dataset rather than verified real-world stats.
